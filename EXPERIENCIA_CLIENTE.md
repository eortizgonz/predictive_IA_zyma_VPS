# Experiencia de cliente incorporada

Esta versión parte de la capa de presentación completa y no reemplaza los módulos existentes.

## Se conserva
- Vista ejecutiva y KPIs.
- Recomendación ejecutiva y activo prioritario.
- Tabla completa de máquinas.
- Botón Diagnóstico IA por activo.
- Consulta conjunta del manual técnico y el modelo predictivo.
- Gráficos de temperatura, vibración y riesgo.
- Predictive Copilot original.
- Perfiles de Operaciones, Finanzas y Tecnología.
- Impacto operacional y financiero.
- Comparación de escenarios.
- Borrador de órdenes de trabajo.
- ChromaDB, SQLite, RAG, auditoría y API existentes.

## Nueva capa de experiencia
- Centro de accesos rápidos sin reemplazar el dashboard.
- Chat lateral flotante disponible desde cualquier sección.
- Selector de perfil y máquina dentro del chat.
- Cuatro experiencias funcionales: Consultas, Diagnóstico IA, Finanzas y Tecnología.
- Diagnóstico IA abre el modal original con manual + modelo.
- Finanzas y Tecnología ejecutan consultas reales al endpoint del Copilot.
- Acciones dentro de las respuestas: explicar, comparar escenarios y preparar orden.
- Diseño responsive para escritorio y móvil.
